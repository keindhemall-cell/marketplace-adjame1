MARKETPLACE ADJAMÉ — PROTOTYPE MULTIPAGES UI/UX

Cette archive contient un prototype de navigation statique. Il s’agit de pages de démonstration,
pas d’une application e-commerce connectée.

POUR L’OUVRIR
1. Décompressez le ZIP.
2. Ouvrez index.html dans votre navigateur.
3. Utilisez le menu, les liens, les catégories, la recherche et les fiches produits pour naviguer.

PAGES INCLUSES
- index.html : accueil
- categories.html : toutes les catégories
- categorie.html : page dédiée à une catégorie
- recherche.html : résultats de recherche sur des données fictives
- produit.html : fiche produit
- panier.html : panier illustratif
- connexion.html : maquette de connexion
- inscription.html : maquette d’inscription
- commandes.html : exemple d’espace client / achats
- suivi.html : maquette de suivi de colis
- aide.html : aide et contact
- styles.css : styles responsive
- app.js : navigation et rendu des données de démonstration

LIMITES VOLONTAIRES
- Aucun backend ni base de données.
- Aucun compte n’est créé et aucune connexion réelle n’est effectuée.
- Aucun panier réel, commande, paiement, remboursement ou suivi logistique.
- Les formulaires affichent seulement un message de démonstration.
- Les produits, prix, vendeurs, commandes et coordonnées sont fictifs.
- Les images externes nécessitent une connexion Internet.

IMPORTANT : conservez styles.css et app.js dans le même dossier que les pages HTML.
Si le site semble sans mise en forme, vérifiez que styles.css est bien présent à côté de index.html.
